# Happiness Analysis 2021

## Project Overview
This project analyzes the World Happiness Report 2021 dataset to uncover insights into global happiness. The dataset includes metrics such as happiness scores, GDP per capita, social support, healthy life expectancy, and more, which are used to evaluate and compare happiness levels across countries.

## Objectives
- Understand the distribution of happiness scores across countries.
- Identify factors contributing to happiness, such as GDP, social support, and life expectancy.
- Visualize key insights using plots and charts.

## Dataset
Two datasets are used in this project:
1. **World Happiness Report 2020**: Contains historical data from 2005-2020.
2. **World Happiness Report 2021**: Focuses on 2021 happiness metrics.

## Technologies Used
- **Python**: For data manipulation and analysis.
- **Pandas**: To process and clean the data.
- **Matplotlib** and **Seaborn**: For data visualization.

## Key Features
- Distribution analysis of happiness scores.
- Correlation analysis between happiness and contributing factors.
- Country-specific visualizations.

## Visualizations
1. **Top 10 Happiest Countries (2021)**: A bar plot showing the happiness scores of the top 10 happiest countries.
2. **GDP vs. Happiness Score**: A scatter plot illustrating the relationship between GDP per capita and happiness scores.
3. **Social Support Comparison**: A bar plot comparing social support in the top 10 happiest countries.
4. **Correlation Heatmap**: A heatmap showing relationships between key metrics such as GDP, social support, and life expectancy.

## How to Run
1. Install required libraries:
   ```bash
   pip install pandas matplotlib seaborn
   ```
2. Load the provided Jupyter Notebook.
3. Run the notebook to explore the visualizations and insights.

## Results
The analysis highlights the following:
- Countries with higher GDP per capita and strong social support systems tend to have higher happiness scores.
- Healthy life expectancy and freedom to make life choices are significant contributors to happiness.
